\section{Discussion and Limitations}
\label{sec:discussion}

\paragraph{Complexity and Supervision.}
CID adds typed continuous cognition, persistent bindings, event scheduling, and local diffusion control; these costs are justified only if they outperform a simpler asynchronous autoregressive agent, which is therefore a central falsification baseline. Typed cognitive targets and binding lifecycles are also not naturally available: distillation, weak source-dependency supervision, and synthetic schedules can bias the representation toward their generator. Roles, anchors, and dynamically registered source descriptors may consequently drift across checkpoints or domains.

\paragraph{Train--Runtime Contract Sensitivity.}
An early frozen-backbone prototype showed that semantically irrelevant representation choices can block an otherwise useful tool policy. Random physical-slot labels, capacity-dependent positional shifts, and incompatible display-shape assumptions motivated slot-invariant allocation, capacity-invariant logical positions, and fixed physical display budgets with explicit realized-length semantics. Formal evaluation therefore uses a model retrained from the base checkpoint under the corrected contract rather than an inference-only patch to the prototype.

\paragraph{Facts, Compute, and Privacy.}
The protected fact channel is not guaranteed to be true: pinned values can be wrong or stale, and sources may conflict, so provenance and uncertainty remain necessary. Persistent re-projection may reduce I/O while increasing model compute and retained state; deployments therefore need explicit update, refresh, and memory budgets. Latent cognition may also contain sensitive source-derived information, so operational logging should expose typed metadata and provenance without requiring disclosure of private reasoning content.

\paragraph{Read-Only Scope.}
This work restricts interaction to read-only retrieval, files, databases, calculators, clocks, environment state, and streams. This isolates sustained asynchronous perception from commitment and rollback. Side-effecting tools introduce stateful interaction and policy-compliance requirements that are explicitly exercised by modern agent benchmarks~\citep{yao2024taubench,lu2024toolsandbox}; authorization, idempotency, confirmation, and recovery mechanisms remain future work for CID. Likewise, multimodal extension is plausible but unevaluated; sustained perception is only a systems analogy and not a claim about human cognition.
