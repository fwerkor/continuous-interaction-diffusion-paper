\section{Conclusion}
\label{sec:conclusion}

We introduced Continuous Interaction Diffusion, a diffusion-native model--runtime architecture with typed revisable cognition and persistent asynchronous perception. The first Stage-A study is deliberately diagnostic: StageA-v0 executes no tools under its original materialization contract, while a no-weight-change allocation intervention recovers the need$\rightarrow$binding$\rightarrow$tool$\rightarrow$observation$\rightarrow$projection path on 29/32 held-out NQ cases at the original geometry and 30/32 with training-aligned geometry. This isolates train--runtime inconsistencies rather than establishing final task quality. We retain that negative result as RQ1, retrain from the same base under the corrected contract for RQ2, and use later RQs to test the broader falsifiable claim that diffusion-native revision can improve reliable tool interaction and latency overlap over simpler alternatives.
